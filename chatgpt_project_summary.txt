# Amit Mobile Shop - Full-Stack Web Application

A complete, production-ready, highly professional web application built strictly for **Amit Mobile Shop**, located at **Kuk Nagar Grint Rd, Khorare, Uttar Pradesh 271312**.

---

## Business Information
- **Business Name**: Amit Mobile Shop
- **Exact Address**: Kuk Nagar Grint Rd, Khorare, Uttar Pradesh 271312
- **Google Maps**: [View on Google Maps](https://maps.app.goo.gl/Cumott8vek7HA85K9)
- **Contact Numbers**: `+91 6306657432`, `+91 9721996477`
- **WhatsApp Integration**: Direct pre-filled click-to-chat links for products & repair bookings.
- **Financing Partners**: Bajaj Finserv (No Cost EMI), TVS Credit (Rural Finance), Samsung Finance+ (Digital Paperless).

---

## Technical Stack
- **Frontend**: React (Vite) + Tailwind CSS + Lucide Icons (Bilingual Hindi 🇮🇳 / English 🌐)
- **Backend**: FastAPI (Python 3) + Uvicorn + Pydantic
- **Database**: PostgreSQL / Supabase Schema (`backend/schema.sql`) with zero-config SQLite engine (`backend/ams_store.db`)
- **AI Integration**: Google GenAI SDK (Gemini Pro / Flash) with domain-specific pricing heuristics fallback

---

## Quick Start Guide

### 1. Run Backend Server (FastAPI)
```bash
# Navigate to backend and install requirements (if not already installed)
pip install -r backend/requirements.txt

# Start the FastAPI server
python backend/run.py
```
Backend API will run at **http://localhost:8000**
- Health Check: `http://localhost:8000/api/health`
- Interactive API Docs: `http://localhost:8000/docs`

### 2. Run Frontend Server (React + Vite)
```bash
# In another terminal window:
cd frontend
npm install
npm run dev
```
